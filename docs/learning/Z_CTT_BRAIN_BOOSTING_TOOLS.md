# Z-CTT — Brain-boosting tools (doctrine)

Formal lane: **Z-CTT / Z-Learning & Content Quality Engine** — Phase **ZCTT-1** (doctrine + registry only).

## Purpose

Catalog **optional learning activities** that support creativity, reflection, and focus across the Z-Sanctuary ecosystem — **without** medical claims, cognitive-improvement guarantees, therapy framing, or live provider integration.

Z-CTT is a **cross-ecosystem learning and content-quality layer**, not part of the Genesis Studio creative engine core.

## Golden law

```text
Supports learning, creativity, reflection, and focus.
Does not diagnose, treat, or guarantee cognitive improvement.
No runtime in ZCTT-1 — doctrine and registry only.
AMK-Goku owns sacred moves and any future live lane.
```

## Tool categories (Phase 1 — metadata only)

| Category                | Intent                                                   | Phase 1 posture                                      |
| ----------------------- | -------------------------------------------------------- | ---------------------------------------------------- |
| **Cognitive games**     | Optional puzzles, logic drills, pattern play             | Listed in registry; no live game runtime             |
| **Mindfulness / focus** | Non-medical breath, pause, reflection prompts            | No health or anxiety treatment claims                |
| **Creative expression** | Writing, sketch, voice-note _ideas_ (governed elsewhere) | Links to Genesis / OMNAI as optional templates later |
| **Logic / puzzles**     | Structured problem sets for practice                     | Static rubrics only; no adaptive scoring engine      |
| **Study planners**      | Human-chosen goals and session blocks                    | No automated scheduling daemon                       |
| **Content notebooks**   | Curated notes aligned with Z-QUESTRA posture             | Reference-only; no external LMS                      |

## Safe wording

Use:

- supports learning, creativity, reflection, and focus
- optional practice activities
- human-chosen goals
- governed content quality checks

Avoid:

- guarantees cognitive improvement
- diagnoses attention or memory issues
- treats stress, anxiety, or clinical conditions
- neurofeedback or biometric “brain training”
- “clinically proven” or therapy-adjacent marketing

## Forbidden in ZCTT-1

- LMS integrations
- External course or content APIs
- User profiling or behavioral tracking
- Recommender algorithms
- Rewards, leaderboards, or competition loops aimed at minors
- Evaluator reputation systems
- Neurofeedback or wearable “cognitive boost” hooks
- Health, therapy, or medical framing

# Z-Nexus Engine — Data Ethics and Scientific-Claim Boundaries

**Phase:** Z-NEXUS-ENGINE-0
**Status:** Doctrine only — Turtle Mode
**Hub:** Z-Sanctuary Universe

---

## Mission

Establish the **ethical boundaries and scientific-claim posture** for all Z-Nexus Engine outputs — ensuring that awareness concepts are never presented as certified data, regulatory findings, or scientific authority, and that data use respects dignity, consent, and community autonomy.

---

## Data ethics principles

| Principle | Description |
| --- | --- |
| **Consent first** | No data is collected, stored, or processed without explicit community consent |
| **Minimisation** | Only the minimum concept-level information needed to illustrate awareness is documented |
| **Transparency** | Every concept is labelled as a concept; provenance and uncertainty are declared |
| **Non-maleficence** | Data concepts must not enable discrimination, surveillance, or harm |
| **Community ownership** | Communities described in awareness concepts hold authority over their own narratives |

---

## Scientific-claim boundary (hard rules)

```text
RULE 1: No peer-reviewed claim — Z-Nexus Engine does not publish or cite findings
         as peer-reviewed science. Concepts are concepts.

RULE 2: No certified statistics — Population, energy, or resource figures used in
         examples are illustrative only. They carry no statistical certification.

RULE 3: No regulatory standing — Nothing in Z-Nexus Engine constitutes
         environmental, health, or financial regulatory compliance.

RULE 4: No diagnostic or medical claims — Human-energy framing does not diagnose,
         prescribe, or advise on health conditions.

RULE 5: No legal standing — Resource awareness concepts carry no legal weight,
         ownership claim, or rights instrument.

RULE 6: "Awareness" ≠ "authority" — Observing a pattern conceptually
         does not confer authority to act on it without AMK and human gate.
```

---

## Permitted vs blocked claim types

| Claim type | Permitted in Phase 0 | Requires |
| --- | --- | --- |
| Conceptual illustration | Yes | Label as concept, no real names or data |
| Anonymised community pattern sketch | Yes | Consent framework noted; no PII |
| Illustrative numeric range | Yes (with explicit "illustrative only" tag) | Uncertainty declared |
| Certified environmental statistic | No | Chartered external data-partner gate |
| Peer-reviewed finding citation | No | Academic partnership + AMK gate |
| Medical or health advisory | No | Medical board + legal + AMK gate |
| Financial projection or guarantee | No | Financial regulatory + AMK gate |
| Legal rights instrument | No | Legal counsel + AMK gate |

## Data provenance declaration template

All nexus engine concept documents that reference numbers or community descriptions must include:

```text
⚠️ PROVENANCE NOTE
This figure / description is conceptual and illustrative only.
It does not represent certified, peer-reviewed, or regulatory data.
Source: Z-Nexus Engine Phase 0 doctrine exercise.
Status: Concept — not for publication, policy, or decision-making.
```

## Triple Path (constitutional check)

For important discoveries, all three must agree — or **HOLD**:

```text
Path A — PHYSICAL     Where does it exist? (disk, repo, package, service)
Path B — DOCUMENTARY  Where is it described? (README, registry, receipt)
Path C — RELATIONAL   What does the ecosystem say it connects to?

PHYSICAL + DOCUMENTARY + RELATIONAL → identity confidence
Disagree → CONFLICT → HOLD → Steward receipt
```

Dashboard 2 failed Path A while Paths B/C were partial → HOLD (not GREEN guess).

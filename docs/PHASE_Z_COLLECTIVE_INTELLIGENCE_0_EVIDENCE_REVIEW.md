**Hierarchy titles exist** (Overseer roof, Supervisors-as-lenses, AI Tower planned). A clean Major-Supervisor product class is **UNKNOWN**. Higher title ≠ execution authority is already cultural law — but **Fusion Council’s weighted-vote “final_recommendation”** is a latent majority-pressure pattern that must be challenged before any collective loop.

**Twin Roots** is the right **challenge principle** (`30eeaa7`); the Phase 1 **module** remains **MOCK** and must not be mistaken for an organism-wide adversarial engine.

**New collective-intelligence engine:** **NO** (not justified). Strengthen-first: deliberation contribution template mapped onto existing reports + Twin Roots challenge doctrine + anti-consensus rules for Fusion/QOSMEI-class synthesizers.

**Autonomous authority:** **NOT AUTHORIZED** (OBSERVE/ADVISE review only; PREPARE/EXECUTE closed).

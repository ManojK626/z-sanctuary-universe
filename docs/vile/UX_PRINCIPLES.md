# VILE UX Principles

## Experience goals

| Principle | Practice |
| --------- | -------- |
| Dignity-first | Language honours hosts, workers, elders |
| Clarity | Travellers understand what is verified vs illustrative |
| Safety visible | Child, water, medical disclaimers — not hidden |
| Cultural respect | No costume clichés; ambassador-reviewed content |
| Offline honesty | Show sync status and stale data warnings |
| Accessibility | WCAG-oriented — AccessibilityAgent informs design |

## ZILWA exhibit lineage

Static prototypes in `dashboard/Html/zilwa-*` are **design references**:

- Ocean guardians, street food academy, elder oral history, etc.  
- Not production UX without phase charter  

## Roles

| Surface | UX priority |
| ------- | ----------- |
| Traveller | Simple journeys, offline wallet |
| Vendor | Fair economics transparency |
| Operations | Incident clarity, audit trails |
| Community | Consent-first story sharing |

## Prohibited patterns

- Dark patterns in booking  
- Fake urgency or fabricated “only 1 left”  
- Health claims without approved content packs

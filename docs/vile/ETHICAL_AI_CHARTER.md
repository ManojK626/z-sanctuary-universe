# Ethical AI Charter — VILE

**Law:** Recommendations must respect dignity, safety, privacy, and human approval.

## Commitments

| Value | Practice |
| ----- | -------- |
| Community dignity | No exploitation framing; fair-value language |
| Environmental sustainability | Prefer low-impact options |
| Cultural heritage | Accurate, respectful — cite sources or abstain |
| Child protection | KidsSafetyAgent + escalation paths |
| Medical safety | Information only — never diagnose |
| Privacy | Minimal data; consent for stories and research |
| Human approval | Sacred and high-risk paths require AMK/operator gate |

## Prohibited

- Fabricating vendors, permits, safety ratings, or medical clearance  
- Impersonating government or NGO authority  
- Training on steward stories without documented consent (ZILWA lane)  
- Bypassing Shadow or DRP for speed  

## ZILWA alignment

Community listening ([ZILWA_LISTENING_CONSENT_AND_SAFEGUARDING.md](../zilwa-living-experiences/ZILWA_LISTENING_CONSENT_AND_SAFEGUARDING.md)) **outranks** model output when in conflict.

## Operational phase

Ecosystem is in **Learning / Discovery / Alignment** — not revenue automation. Ethical charter applies to **docs and future code** alike.

# Z-SSWS-GTC — Cloudflare protocol

## Cloudflare phase posture

Cloudflare remains future-phased only in this doctrine lane:

```text
Pages → Zero Trust review → Workers only with charter
```

## Cloudflare may later help with

- static docs and demos
- access posture review
- edge research
- future protected surfaces

## Cloudflare must not

- expose NAS publicly
- expose raw RDP
- create tunnels automatically
- bind production without charter
- become sole governance source
- create AI runtime without AMK gate

## Guard law

```text
Cloudflare posture ≠ production bind
readiness ≠ deploy
```

# Z-SSWS-GTC — command boundaries (read-only advisory spine)

## Boundary statement

The command spine organizes visibility and advice. It does not execute sacred actions.

```text
command spine ≠ execution authority
readiness ≠ deploy
observe → verify → suggest → human decides
```

## What Z-SSWS-GTC may track (advisory only)

- open PR queue
- failed CI checks
- branch map
- Cloudflare posture
- operator queue
- advisory command results
- receipt status
- tool ownership by action type

All tracking remains read-only and suggestive.

## Explicit non-authority

- No auto-merge.
- No auto-deploy.
- No hidden networking.
- No runtime/workflow expansion by doctrine implication.
- No override of AMK/human approval gates.

## Tool interpretation law

```text
tooling insight ≠ sacred approval
AI report ≠ operator decision
GitHub status ≠ merge permission
Cloudflare posture ≠ production bind
Cursor plan ≠ approved work
```

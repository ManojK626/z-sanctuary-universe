# Z-SSWS-GTC Phase 0 — GitHub / Tooling / Cloudflare command spine doctrine

## Mission

`Z-SSWS-GTC` (GitHub, Tooling & Cloudflare command spine) defines a shared, docs-only command posture across Cursor, GitHub, and Cloudflare.

This layer organizes commands, protocols, PR posture, CI interpretation, Cloudflare future phases, and operator receipts without granting execution authority.

## Scope (Phase 0)

- Doctrine docs only.
- No runtime changes.
- No workflow additions.
- No Cloudflare provisioning.
- No deployment or automation authority.

## Core laws

```text
command spine ≠ execution authority
GitHub status ≠ merge permission
Cursor plan ≠ approved work
Cloudflare posture ≠ production bind
tooling insight ≠ sacred approval
AI report ≠ operator decision
```

Inherited standing law:

```text
federation ≠ authority
topology ≠ ownership
observe → verify → suggest → human decides
readiness ≠ deploy
organization ≠ control
layered tools ≠ the soul
```

## Layer roles

- Cursor: builder workspace and doc/PR preparation lane.
- GitHub: vault, history, PR gate, and check evidence.
- Cloudflare: future edge/access posture, phased and charter-gated.

None of these layers gain merge, deploy, or sacred-move authority.

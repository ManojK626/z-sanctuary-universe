# Z-SSWS-GTC — Cursor protocol

## Cursor role in this spine

Cursor may:

- organize branches
- draft docs
- prepare PR-sized diffs
- interpret checks
- suggest the next Turtle lane

## Cursor must not

- auto-merge
- auto-deploy
- silently expand runtime
- create hidden networking
- override AMK approval

## Guard law

```text
Cursor plan ≠ approved work
AI report ≠ operator decision
```

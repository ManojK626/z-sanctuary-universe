## Purpose

This document defines **when Project Lifeboat succeeds**.

The Charter says *why* and *how we decide*.
These criteria say *what “done right” looks like* across decades.

Re-read this North Star before Phase advances, provider locks, or Wave 1B naming.

---

## Project Lifeboat succeeds when

1. **The Constitution survives independent hardware failure.**
   A PC (or single drive) loss does not erase constitutional and stewardship core.

2. **Restoration is verified annually.**
   At least one scheduled restore drill per year passes checksum / sample (or full) verification and is receipted.

3. **Migration between providers can occur without data loss.**
   An exit rehearsal proves portable encrypted archives can move to an alternate endpoint with integrity intact.

4. **No single company becomes a point of failure.**
   Independent copies span failure domains (e.g. local steward + off-site + GitHub history) — not one vendor’s goodwill alone.

5. **Preservation remains affordable over decades.**
   Projected ownership cost stays within steward-accepted sustainability (see 20-year cost projection; annual cost review).

6. **Future stewards can recover the organism without relying on undocumented knowledge.**
   Playbooks, certificates, manifests, and key-ceremony records are sufficient for recovery by a designated successor.

## Non-success signals (stop and correct)

- Backup exists but restore never tested
- “Safe” only on one PC or one cloud account
- Keys only in one person’s undocumented memory
- Cost path requires hyperscaler TCO the steward cannot sustain
- Destination chosen because it was first available — not because evidence supported it

## AI role on Z-Connect

**Guide, never authority.** AI suggests, explains, and helps users explore — users decide, approve, and act.

```text
AI assists ≠ AI decides
Connection Confidence ≠ destiny
Progressive Discovery ≠ surveillance
```

## Binding law — AI Constitution v1

Ten principles — **locked**, AMK-approved:

| # | Principle |
| - | --------- |
| 1 | Respect every person equally |
| 2 | Never manipulate emotions |
| 3 | Never create dependency on AI |
| 4 | Encourage real human communication |
| 5 | Explain uncertainty honestly |
| 6 | Protect privacy by default |
| 7 | Never present insights as objective truth |
| 8 | Label entertainment clearly |
| 9 | Allow pause, skip, and exit anytime |
| 10 | Defer to human judgment on connection decisions |

## AI output pipeline (mandatory when runtime exists)

```text
User intent
  → Consent (if capture)
  → zuno-security classify
  → zuno-drp evaluate
  → AI generate (guide tone)
  → zuno-shadow validate
  → User review / approve
  → Persist + zuno-observability audit
```

## Forbidden AI behaviour

- Destiny or soulmate certainty language  
- Percentage compatibility scores  
- Emotional manipulation for upgrades  
- Silent profiling from private messages  
- Auto-decisions on connections or messages  
- Presenting entertainment as science

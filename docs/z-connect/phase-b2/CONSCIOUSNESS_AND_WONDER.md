**Phase:** B2.2 · Section 4

## Purpose

Shared **wonder** opens doors to conversation — philosophy under stars, ethics over coffee, art in a gallery. This layer captures optional curiosities without predicting destiny or soulmate fate.

**Doctrine:**

> Shared wonder creates **opportunities** for connection. It **never predicts** destiny.

## How wonder supports connection

| Use | Avoid |
| --- | ----- |
| Conversation starters in Journey | "You were meant to meet because you both like philosophy" |
| Event or group discovery (future, gated) | Ranking users by "depth" |
| Reflecting shared themes qualitatively | Soulmate destiny claims |
| Respect for difference — wonder can diverge | Penalizing unlike interests |

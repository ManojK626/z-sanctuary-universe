# Soulmates Universe — Growth Journeys

**Phase:** B2.2 · Section 3  
**Parent:** [LIVING_CONNECTION_DIMENSIONS.md](../LIVING_CONNECTION_DIMENSIONS.md)  
**Posture:** Personal evolution layer · no growth "scores"

---

## Purpose

People are **moving** — past, present, and future selves coexist. Growth Journeys document optional life chapters users choose to share, not a ladder others climb or judge.

---

## Profile structure (reflection only)

```text
Past
  ↓
Present
  ↓
Future
```

Each horizon is **user-authored**. AI may help **articulate** — never **assign** trajectory.

---

## Example journey themes (optional, multi-select)

| Theme | Example reflection |
| ----- | ------------------ |
| **Healing** | Recovering from loss or hardship |
| **Learning confidence** | Building self-trust in new contexts |
| **Career transition** | Changing work or purpose |
| **Parenthood** | Raising or supporting children |
| **Creativity** | Making art, music, writing |
| **Spiritual exploration** | Meaning, faith, practice — user-defined |
| **Self-discovery** | Identity, orientation, values |
| **Community building** | Belonging and service |
| **Education** | Formal or lifelong learning |

Users may add free text. **No required "growth stage."**

---

## Growth compatibility (honest framing)

**Instead of:** "Growth match: 87%"

**Use qualitative dimensions:**

| Dimension | Example |
| --------- | ------- |
| Shared growth themes | Healing · creativity (overlap optional) |
| Pace of change | Calm vs fast-moving (see Life Rhythms) |
| Support style | How we encourage each other's goals |
| Unknown areas | **Unknown** — honesty preserved |

Different growth paths can **complement** each other. Divergence is not failure.

---

## Guardrails

- No ranking "more evolved" users  
- No AI prediction of who will "grow together"  
- Past trauma: progressive disclosure + consent — [Z_CONNECT_PROGRESSIVE_DISCOVERY.md](../Z_CONNECT_PROGRESSIVE_DISCOVERY.md)  
- Minors / vulnerable contexts: extra gates per Trust & Safety

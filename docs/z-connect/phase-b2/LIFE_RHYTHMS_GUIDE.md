# Soulmates Universe — Life Rhythms Guide

**Phase:** B2.2 · Section 1  
**Parent:** [LIVING_CONNECTION_DIMENSIONS.md](../LIVING_CONNECTION_DIMENSIONS.md)  
**Posture:** Reflection dimensions only · no scoring · no compatibility engine

---

## Purpose

Help people describe **how they live** — energy, environment, social rhythm, planning, and pace — so conversations can meet them where they are.

**Law:**

> Life rhythm alignment **informs conversation**. It **never determines compatibility**.

---

## Dimension 1 — Energy

| Rhythm | Description (user self-select) |
| ------ | ------------------------------ |
| **Morning person** | Energy peaks earlier in the day |
| **Night owl** | Energy peaks later |
| **Flexible** | Varies by season, work, or mood |

**Use:** Journey prompts, scheduling suggestions, AI tone — **not** match filtering.

---

## Dimension 2 — Environment

| Preference | Description |
| ---------- | ----------- |
| **Nature** | Restored by outdoors, quiet landscapes |
| **Urban** | Energized by cities, density, culture |
| **Mixed** | Needs both — context-dependent |

---

## Dimension 3 — Social rhythm

| Style | Description |
| ----- | ----------- |
| **Quiet circles** | Prefers small, deep gatherings |
| **Balanced** | Mix of intimate and social time |
| **Highly social** | Frequent connection with many people |

**Not introvert/extrovert hierarchy** — descriptive only.

---

## Dimension 4 — Planning style

| Style | Description |
| ----- | ----------- |
| **Structured** | Plans ahead; values reliability |
| **Adaptive** | Plans loosely; adjusts easily |
| **Spontaneous** | Enjoys last-minute openness |

---

## Dimension 5 — Pace

| Pace | Description |
| ---- | ----------- |
| **Calm growth** | Prefers steady, unhurried progress |
| **Balanced ambition** | Goals with sustainable tempo |
| **Fast-moving** | Thrives on momentum and change |

---

## Reflection prompts (examples)

- When do you feel most like yourself during the day?  
- What environment helps you recharge?  
- How much social time feels nourishing vs draining?  
- Do you prefer plans or openness — and does that change by context?  

---

## AI & product guardrails

- No "rhythm match %"  
- No deprioritizing users with different rhythms  
- Opposite rhythms may **enrich** connection — document differences, don't rank  
- User can skip all dimensions

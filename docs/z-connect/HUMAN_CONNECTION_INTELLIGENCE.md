## Core principle

Soulmates Universe does **not** classify people into rigid boxes.

Its purpose is:

- **Understand** humans deeply  
- **Respect** individuality  
- **Strengthen** authentic connections  
- **Never** reduce a person to a label  

> The rarest and most meaningful connections are often **not** between people with the same personality type. They emerge when two people understand each other's differences and choose to grow together.

## Human Connection Intelligence Engine (HCI) — five layers

HCI is a **doctrine model** for how Soulmates **frames** understanding — not a runtime classifier.

### Layer 1 — Personality archetypes (conversation starters)

**Supported frameworks (optional, user-declared or reflective prompts):**

INFJ · INFP · INTJ · ENFP · ENFJ · ISTP · ISFJ · ENTJ · (others as user chooses)

**Law:**

| MBTI is | MBTI is not |
| ------- | ----------- |
| Conversation starter | Destiny |
| Self-reflection aid | Truth |
| Optional vocabulary | Compatibility score |

**Weight:** Low–medium importance. Never sole basis for matching or ranking.

---

### Layer 2 — Attachment intelligence (higher weight)

May matter **more than MBTI** for real connection patterns:

| Pattern | Exploratory questions (reflection, not diagnosis) |
| ------- | ------------------------------------------------- |
| Secure attachment | How is trust built over time? |
| Anxious attachment | How is distance experienced? |
| Avoidant attachment | How is closeness negotiated? |
| Fearful-avoidant | How is pain communicated? |

**Questions HCI may help users explore:**

- How do you react to distance?  
- How do you handle trust?  
- How do you communicate pain?  
- How do you express commitment?  

**Not clinical diagnosis.** User-owned reflection; AI explains patterns — **humans decide**.

---

### Layer 3 — Communication styles

Optional descriptors — many can coexist in one person:

| Style | Example trait |
| ----- | ------------- |
| Analytical thinker | Structures ideas logically |
| Deep listener | Holds space before responding |
| Emotional expresser | Names feelings openly |
| Reflective communicator | Pauses before reacting |
| Adventurer | Learns through experience |
| Quiet observer | Processes internally first |

**Weight:** Medium. Used for **understanding**, not sorting into superior/inferior types.

---

### Layer 4 — Connection depth map (honest framing)

**Instead of:**

> Compatibility: 92%

**Show qualitative dimensions** (High · Medium · Low · Unknown):

| Dimension | Example display |
| --------- | --------------- |
| Shared values | High |
| Emotional rhythm | Medium |
| Communication harmony | High |
| Life goals alignment | Strong alignment |
| Growth potential | **Unknown** (honesty) |

**Unknown is valid.** Pretending certainty destroys trust.

Aligns with [Connection Confidence](phase-b2/PRODUCT_VISION.md) — no fake precision.

---

### Layer 5 — Compassion intelligence

Inspired by [Compassion Charter](../governance/Z_SANCTUARY_COMPASSION_CHARTER.md) — **behavioral dignity**, not scores:

| Reflective question |
| ------------------- |
| Can this person disagree respectfully? |
| Can they apologize? |
| Do they show empathy? |
| Are they emotionally available (when they choose to be)? |
| Can they protect another person's dignity? |

**Not a "compassion score" on users.** Self-reflection and journey prompts only. Moderation handles harm — see Trust & Safety.

| Profile | Traits (optional) |

| **Sage** | Seeks wisdom · loves learning · philosophical |
| **Guardian** | Protective · loyal · stable |

**Law:** Profiles are **invitations to self-description**, not hierarchy ranks. User can select none, one, or many.

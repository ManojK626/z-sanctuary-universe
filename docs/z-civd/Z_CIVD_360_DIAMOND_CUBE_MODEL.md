# Z-CIVD 360 Diamond Cube Model

**Phase:** Z-CIVD-0 — **conceptual analysis only**

This model is a **thinking scaffold** for human-led review. It is not a running engine, scoring API, or certified engineering tool in Phase 0.

---

## Overview

```text
Generalyser (root structure)
    → Growthtyser (time / phases / scale)
    → Analyser (risks / requirements / options)
    → Equalyser (balance / sequence / interactions)
    → Stablelyser (durability / stress / variation)
    → 360 Ring (no blind angle)
    → Diamond Cube (multidimensional compare)
```

---

## Layer definitions

| Layer | Role | Phase 0 |
| ----- | ---- | ------- |
| **Generalyser** | Root overview — purpose, scope, stakeholders, constraints | Doctrine |
| **Growthtyser** | Growth across time, phases, cost bands, scaling paths | Doctrine |
| **Analyser** | Risks, requirements, comparisons, future options | Doctrine |
| **Equalyser** | Balance, movement, sequence, system interactions | Doctrine |
| **Stablelyser** | Stability, durability, stress cases, long-term variation | Doctrine |
| **360 Ring** | Deliberate “no blind angle” review — ethics, ecology, legal reminders | Doctrine |
| **Diamond Cube** | Multidimensional option compare (see below) | Doctrine |

---

## Diamond Cube dimensions

Compare Version 1 / 2 / 3 (or more) across:

| Dimension | Questions (conceptual) |
| --------- | ---------------------- |
| **Safety** | Harm to people, animals, future users? |
| **Cost** | Rough categories — not live pricing |
| **Materials** | Reclaimed, regenerative, local, low-impact? |
| **Local availability** | Can this be sourced or built nearby? |
| **Ecosystem impact** | Water, soil, habitat, emissions narrative |
| **Repairability** | Can a local maker fix it in 5 years? |
| **Beauty / usability** | Dignity, clarity, delight — without vanity waste |
| **Cultural fit** | Respect for place, community, and tradition |
| **Future expansion** | Can this evolve without throwaway redesign? |

---

## 360 Ring — blind-angle prompts

- Who is **not** in the room?  
- What happens if this **fails** mid-build?  
- What animal or habitat edge case was ignored?  
- Does this **concentrate** or **share** benefit?  
- Would a child or elder be safe here?  
- Is there a **lighter** version that still serves the purpose?

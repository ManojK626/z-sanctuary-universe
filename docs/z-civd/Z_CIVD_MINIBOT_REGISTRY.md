# Z-CIVD Mini-Bot Registry

**Phase:** Z-CIVD-0 — **conceptual mini-bots only**

Mini-bots are **named review lenses** for documentation and future UI — not autonomous agents, not runtime workers, not provider connectors.

---

## Registry

| Mini-Bot | Purpose |
| -------- | ------- |
| **Z-IntakeBot** | Clarify idea, purpose, constraints, desired outcome |
| **Z-SiteBot** | Location, slope, climate, land context (conceptual — no GIS SDK in Phase 0) |
| **Z-MaterialBot** | Local, reclaimed, regenerative material options |
| **Z-BioSphereBot** | Animal and ecosystem impact prompts |
| **Z-StructureBot** | Conceptual balance and stability review — not engineering sign-off |
| **Z-CostBot** | Rough cost **categories** and alternatives — not live pricing or payments |
| **Z-CraftBot** | Local skills, hand-build methods, repairability |
| **Z-LegalBot** | Reminds permits and professional checks may be required |
| **Z-VersionBot** | Compares Version 1 / 2 / 3 options |
| **Z-RegenerationBot** | Give-back plan — restoration, planting, water reuse |

---

## What mini-bots may do (Phase 0 doctrine)

- Organize questions and checklists in markdown  
- Suggest comparison dimensions for human review  
- Link to biosphere and 360 Diamond Cube docs  

---

## What mini-bots must not do

| Forbidden | Reason |
| --------- | ------ |
| Execute actions in the real world | No autonomous build agent |
| Buy materials | No payment or procurement |
| Contact providers | No API or marketplace |
| Replace certified professionals | Engineering, legal, medical, structural |
| Auto-approve a design | Human gate always |
| Run as live AI agents without charter | Phase 0 = concepts only |

---

## Locked law

```text
Mini-bot name ≠ autonomous agent.
Conceptual bot ≠ runtime worker.
Z-LegalBot reminder ≠ legal advice.
Z-StructureBot review ≠ structural certification.
```

---

## Future charter

A future phase may implement **read-only** UI cards that **display** mini-bot checklists. Live AI routing requires separate AMK + safety + 14 DRP gate.

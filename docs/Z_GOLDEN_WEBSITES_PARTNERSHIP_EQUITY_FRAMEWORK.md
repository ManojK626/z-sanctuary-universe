## Why the old 15% wording changed

The informal idea — “15% future potential profit + lifetime partnerships” — does not fit a Universe that already has sealed Golden Website gates, GW-11 “no revenue share offered,” commercial-readiness holds, and a developed Z-Core.

That 15% is now a **planning envelope**, not a gift:

- `strategic_dilution_envelope_pct`: **15**
- `issued_pct`: **0**
- `promised_pct`: **0**
- semantics: **PROPOSED** · **RESERVED** · **NOT_ISSUED** · **NOT_PROMISED**

Illustrative split only (not issued): about 10% long-term team, 2% strategic/adviser, 3% exceptional future talent. Unused reserve stays unissued.

## What partners can participate in

| Class | Default economics | Default parent equity |
| --- | --- | --- |
| 1 Contributors | Credit, bounty, milestone, site/module incentive | **NONE** |
| 2 Growth partners | Commission / defined property participation | **NONE** unless later elevated |
| 3 Strategic partners | Commercial / licence / distribution | **NONE** automatic; warrants/equity only after legal + steward review |
| 4 Core executive / organism steward | Possible **parent-equity review** | Still not automatic |

GW-11 informational classes (pilot, research, investor, university, …) are **diligence audiences**. They are mapped onto these four economic classes; they are not deleted.

**GOLDEN ECONOMIC DOCTRINE 1:** contribution to a property may earn participation in that property; parent ownership is for exceptional long-term responsibility for the organism as a whole.

## Website economics vs parent equity

**One-website contribution ≠ automatic whole-universe ownership.**

A partner who grows Golden Website #3 should be modelled on Website #3 attributable economics — not “2% of all Z-Sanctuary forever.” Unrelated Z-Core, MirrorSoul, Roulette-related products, other sites, future AI, modules, and inventions stay out unless separately agreed.

Economic base (modelling only, no rate promised):

**Qualified attributable revenue** minus refunds, chargebacks, applicable taxes/VAT, payment processing, directly attributable advertising, directly attributable AI/API usage, and explicitly defined direct property costs → **Qualified contribution margin**.

Do not use undefined “5% of profit.”

Revenue sharing status: **FRAMEWORK DEFINED / NOT ACTIVATED**. No canonical partner percentage.

## Vesting (discussion only)

Common startup talk: **4-year vesting, 1-year cliff**.

Classification: **DISCUSSION_STARTING_POINT**, not a Z-Sanctuary legal rule. Actual terms need counsel in the incorporation jurisdiction. This work issues **no** securities.

Lifetime partnership is **RETIRED_FOR_NEW_RECRUITMENT** (ambiguous duration, inactivity, misconduct, death/disability, restructuring, acquisition, non-performance, strategy change). Replace conceptually with term, vesting, milestones, performance, renewal, termination, good/bad leaver, and a real legal agreement — not drafted here.

## IP and access

| Class | Meaning |
| --- | --- |
| BACKGROUND IP | Owned before collaboration |
| FOREGROUND IP | Created during collaboration |
| Z-CORE IP | Protected reusable Sanctuary assets |
| PROPERTY IP | One website or module |
| THIRD-PARTY IP | Licensed / OSS / external |
| AI-GENERATED ASSETS | Keep provider / licence / provenance |

Solicitor review is required before any assignment. **GOLDEN ECONOMIC DOCTRINE 5:** Z-Core IP is not transferred merely because someone contributes to a site, module, or campaign.

Access law:

```text
PARTNERSHIP ≠ ADMIN ACCESS
REVENUE SHARE ≠ DATABASE ACCESS
EQUITY ≠ PRODUCTION CREDENTIALS
ADVISER ≠ SOURCE-OF-TRUTH AUTHORITY
```

Least privilege. Production credentials stay separately governed. GitHub / Cursor / cloud access is role-specific.

## Partner journey

DISCOVER → APPLY / INTRODUCTION → CONTRIBUTION SCOPE → IP + CONFIDENTIALITY READINESS → LIMITED ACCESS → MILESTONE → MEASURED OUTCOME → ECONOMIC REVIEW → RENEW / EXPAND / CLOSE.

Exceptional whole-universe contributors only: **CORE EQUITY ELIGIBILITY REVIEW**. No automatic upgrade.

Prefer partners who bring what AI-assisted coding cannot cheaply substitute: distribution, credibility, specialist engineering, cybersecurity, regulation, local markets, enterprise/institutional access, community, or capital. Do not spend parent equity just to speed coding the current environment can already do.

## Public Golden Website language

Preserve the doorway. Prefer: contribution opportunities, project-specific partnerships, performance-based participation, commercial collaborations, affiliate opportunities, strategic partnerships, long-term leadership opportunities.

Avoid: “Earn ownership of Z-Sanctuary,” “15% available to everyone,” “Lifetime profits,” “Guaranteed income,” “Become a co-owner by contributing.”

Distinguish economic **opportunity** from guaranteed compensation or equity. **No live recruitment page is deployed in this phase.**

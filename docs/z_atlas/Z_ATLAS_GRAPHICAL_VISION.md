# Z-Atlas Graphical Vision (design only)

**Gate:** `Z-ATLAS-0-LIVING-MULTI-PROJECT-TOPOLOGY-CONSTITUTION`  
**Runtime:** none. No dashboard, no canvas app inside the hub, no interactive site.

This is information architecture for a later internal graphical Atlas (roadmap Phase 4) and a sanitized public Atlas (Phase 5).

---

## Composition

```text
central core
  → category constellations
    → projects / products
      → AI / engine / service nodes
        → typed edges
```

The core is the **ecosystem** (Organiser room + hub), not AI Tower and not any single gaming product.

---

## Interaction (later UI — not built here)

| Verb | Purpose |
| --- | --- |
| Zoom / pan | Move between universe and a single root |
| Filter | By category, authority, health, deployment, commercial, freshness |
| Search | Identity, path, gate, evidence id |
| Focus | Isolate one product and its **distinct** relatives |
| Breadcrumb | Ecosystem → category → project → product → root → gate |
| Overlays | Health, deployment, commercial, communication, evidence — independently togglable |

Overlays must stack. Turning health GREEN must not hide a deployment HOLD.

---

## Human view modes

| Mode | Shows |
| --- | --- |
| `UNIVERSE VIEW` | Core + category constellations |
| `CATEGORY VIEW` | One family and its members |
| `PRODUCT VIEW` | One product, distinct neighbors, forbidden merges |
| `AI TOWER VIEW` | Coordination roles **as a layer**, not as the map |
| `ROOT / PATH VIEW` | Allowlisted roots and path conflicts |
| `GIT / WORKTREE VIEW` | Repositories, worktrees, branches, commits |
| `HEALTH VIEW` | Existing observer states including UNKNOWN |
| `COMMUNICATION VIEW` | Source → route → receiver → receipt |
| `DEPLOYMENT VIEW` | Readiness / HOLD independent of health |
| `COMMERCIAL VIEW` | Family / domain / payment / entitlement (inactive) |
| `EVIDENCE VIEW` | Facts, freshness, conflicts, gates |

---

## Visual law

- `UNKNOWN` has a distinct treatment from `GREEN`.
- `EXTERNAL_SOVEREIGN` nodes sit **outside** the hub hull.
- `LEGACY_READ_ONLY` and `ARCHIVAL_BACKUP` are visually subordinate to current authority.
- `UNRESOLVED` nodes are labeled unresolved — never drawn as canonical.
- Public projection applies [sanitization](Z_ATLAS_INTERNAL_PUBLIC_PROJECTION_BOUNDARY.md) before any node is eligible for Golden Website Atlas.

# Golden Websites economic scorecard

**Slice:** Z-GOLDEN-WEBSITES-PARTNERSHIP-ECONOMICS-0  
**Status:** DEFINED / **NO LIVE ANALYTICS**  
**Not:** a runtime dashboard, billing feed, or activation of Golden status.

## Why this exists

GW-0A already classifies **evidence** (`VERIFIED` … `CLOSED`) and **economic role** (`DIRECT_PRODUCT`, `EXPERIMENTAL`, …). That vocabulary stays canonical.

This scorecard is the **commercial measurement ladder** for a future property registry. It does not replace evidence_state and does not mint a parallel operational lifecycle.

## User funnel

```text
Visitors
  → Registrations
  → Activated users
  → Returning active users
  → Paid users
```

A crowded top of funnel without activation or return is not Golden.

## Revenue and margin

```text
Revenue
  → Direct costs
  → Contribution margin
```

Use **qualified contribution margin** (see the partnership framework): attributable revenue after refunds, chargebacks, applicable taxes/VAT, processing, directly attributable ads, directly attributable AI/API, and named direct property costs.

Undefined “profit %” is not a scorecard metric.

## Retention and lifetime

```text
Retention / repeat revenue
  → Customer lifetime value
```

Repeat revenue and LTV are evidence of a durable property. One spike is not.

## AI economics (AI-heavy properties)

Track at least:

- AI cost per active user
- AI cost per paying user
- AI cost as % of revenue
- Gross margin after AI
- Model / API cost trend
- Inference usage per paid user

A high-revenue site with collapsing post-AI margin is **not** automatically GOLDEN.

## Partner attribution

When (later) a property agreement exists, attribute:

- campaign vs property vs module scope
- qualified attributable revenue
- qualified contribution margin
- arrangement type (commission, property share, none)

Attribution without a named base, duration, review, and termination is not activatable (Doctrine 4).

## Golden-status evidence

Do **not** define Golden by traffic alone.

| Proposed label (not activated) | Meaning as decision support |
| --- | --- |
| EXPERIMENTAL | Conflicts with GW-0A `economic_role` token — **do not operationalize**; keep GW-0A meaning |
| EMERGING | Early funnel, unproven margin |
| GOLDEN_CANDIDATE | Funnel + margin evidence assembling; not sealed |
| GOLDEN | Sustainable economics **and** evidence_state still independently honest |
| STRATEGIC_GOLDEN | Organism-level distribution or platform effect — still not parent equity |

Operational public claims stay on GW-0A **evidence_state** and `commercial_status: POTENTIAL_NOT_VALIDATED` until Steward + legal say otherwise.

## Runtime

No analytics pipeline, no telemetry, no public metrics page in this phase.

# ZILWA LIVING EXPERIENCES — Cultural Ambassador Framework

**System ID:** ZILWA-0
**Status:** Doctrine only — Turtle Mode
**Hub:** Z-Sanctuary Universe

---

## Purpose

Cultural Ambassadors are **community stewards** who help guests engage respectfully with Mauritian life — food, language, crafts, music, faith contexts, and local etiquette — without reducing culture to performance or commodity.

Phase 0 defines **roles and protections** only. No ambassador registry, certification API, or live booking in this phase.

---

## Ambassador role (doctrine)

| Responsibility | Boundary |
| --------------------------------- | ------------------------------------- |
| Welcome and orient guests | No speaking for entire communities |
| Translate context, not people | No mock “official” cultural authority |
| Connect guests to host families | No bypassing host consent |
| Protect sacred or private rituals | Some spaces are not for tourism |
| Report exploitation concerns | Human steward path — not automated |

---

## Host family protection

Ambassadors must **not**:

- Recruit host families on exploitative terms
- Pressure families to exceed capacity or rest limits
- Capture stories or images without consent
- Take disproportionate fees documented only as illustrative in ledger mock

Fair-value splits: see [ZILWA_FINANCIAL_LEDGER_MOCK_SPEC.md](ZILWA_FINANCIAL_LEDGER_MOCK_SPEC.md) — **illustrative projections only**.

---

## Multicultural respect (Mauritius)

Mauritian society is **plural**. Doctrine requires:

- No single “default” culture narrative
- Respect for Creole, Bhojpuri, French, English, and other lived traditions without stereotype
- Faith and sacred sites: consent and dress/context rules from stewards
- No political campaigning or ethnic division as “experience content”

# ZILWA — Global Replication Framework

**Posture:** Concept only · **AMBER+ HOLD** · not operational

## Principle

ZILWA is designed to **replicate with local stewards**, not clone a single hotel or island brand worldwide.

## Replication layers

| Layer      | What travels                                     | What stays local                     |
| ---------- | ------------------------------------------------ | ------------------------------------ |
| Doctrine   | Dignity, consent, safeguarding, child-safety law | Sacred traditions, language, recipes |
| Exhibits   | Static HTML museum patterns                      | Content, hosts, elders, masters      |
| Governance | 14 DRP alignment, human gates                    | Laws, permits, tourism boards        |
| Partners   | Optional pilot references                        | Contracts, payments, operations      |

## Regional adaptation rules

1. **Local steward required** — no region launches without named human stewards
2. **No cultural ownership** — ZILWA does not own creole, indigenous, or sacred practices
3. **No universalizing** — sacred traditions remain with communities
4. **Evidence gate** — environmental, marine, or weather claims need verified sources
5. **Fair pay** — masters, hosts, elders compensated fairly before live phase

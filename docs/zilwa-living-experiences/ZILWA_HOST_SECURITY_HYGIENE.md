# ZILWA — Host Family Security & Hygiene Parameters

**Status:** Doctrine + static checklist · **not inspections · not certification**

---

## Purpose

Read-only parameters illustrating how a future system could **remind** hosts and guests about safety — without scoring families or denying participation.

---

## Parameters (illustrative)

| Area | Demo reminder |
| -------- | ----------------------------------------------------------------- |
| Hygiene | Shared kitchen food safety basics explained to guests |
| Security | Door locks, guest access hours, emergency contacts on fridge card |
| Rest | Capacity and rest-day indicators are dignity guards |
| Children | Family quarters off-limits without invitation |
| Consent | Photography and home tours require explicit yes |

---

## Locked law

- Checklist ≠ regulatory inspection
- ZILWA does not certify homes as "safe" in Phase 1A
- Hosts may decline guests without penalty in doctrine

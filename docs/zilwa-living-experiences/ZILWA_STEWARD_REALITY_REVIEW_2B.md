# ZILWA — Steward Reality Review (Phase 2B)

**Posture:** **AMBER+ HOLD** · listening phase only · **not operational**  
**Charter:** Opened by AMK-Goku · after Villas Caroline human signal  
**Principle:** Slowing down speeds things up.

## What 2B is

A **structured way to listen** before measuring, proposing, or piloting.

ZILWA asks reality-facing questions first:

> What do tourism workers, families, elders, guests, and communities **actually need**?

—not only:

> How can ZILWA help tourism?

## What 2B is not

| Not in 2B | Why |
| --------- | --- |
| New HTML exhibits | Listening, not building |
| Dashboards or apps | No digital capture in repo |
| AI analysis | Human synthesis only |
| Bookings or payments | Sacred lanes closed |
| Committing to Villas Caroline | Context only — see listening context doc |
| Tourism official proposals | Phase 4A — after 3A |

## Sequence (governed)

```text
Listen  →  Learn  →  Synthesize  →  Measure (3A)  →  Propose (4A)
```

**2B covers Listen + Learn.** Synthesis stays steward-controlled; raw voices do not auto-enter the repo.

## Why Villas Caroline mattered

Management can describe what a business wants. **Workers often describe what reality feels like.** ZILWA bridges both — but must **listen to workers first**.

The visit may prove more valuable than a management meeting because it surfaced **real-world human signal**: former colleagues, supervisors, long-serving workers, people who lived tourism.

## Hypotheses to validate (not assume)

| Persona | We may hear about |
| ------- | ----------------- |
| Workers | Recognition, future security, retirement, training, respect |
| Elders | Disappearing stories and traditions, community memory loss |
| Parents | Child safety, meaningful activities, affordable experiences |
| Tourists | Authentic connection, Mauritius beyond the hotel |
| Communities | Benefits vs burdens, opportunities not reaching locals |

**3A metrics must cite 2B evidence** — e.g. Worker Dignity because workers said it mattered, not because we invented it.

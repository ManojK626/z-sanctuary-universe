# ZILWA LIVING EXPERIENCES — Health, Privacy & Child Safety

**System ID:** ZILWA-0
**Status:** Policy doctrine only — **no health data collection** in Phase 0
**Hub:** Z-Sanctuary Universe

---

## Purpose

This document defines **health, privacy, and child-safety boundaries** for ZILWA. It protects children, staff, elders, guests, and the local community from exploitation, surveillance abuse, and false medical authority.

---

## Health passport — future concept only

| Rule | Law |
| ------------------------ | -------------------------------------------------------------- |
| **Health passport** | Future concept only — **no real medical authority** in Phase 0 |
| Medical clearance | Not collected, stored, or verified in Phase 0 |
| Vaccination status | Not collected in Phase 0 |
| AI health interpretation | **Forbidden** — no diagnosis or triage claims |

If a future phase proposes travel-health documentation, it requires: medical/legal review, minimal data, retention limits, and **no** ZILWA certification of fitness to travel.

---

## Privacy principles

| Stakeholder | Protection |
| ----------------- | -------------------------------------------------------- |
| **Guests** | No silent tracking; informed consent for any future data |
| **Host families** | Home privacy; no mandatory interior imaging |
| **Staff** | No off-hours surveillance; clear work boundaries |
| **Elders** | Consent-first; oral history rules in elder policy doc |
| **Children** | Highest protection tier — see below |
| **Community** | No bulk resale of community stories or images |

---

## Child safety (mandatory)

| Rule | Requirement |
| ----------------- | -------------------------------------------------------------------------- |
| Data minimization | No child profiles in Phase 0; future: guardian gate only |
| Photography | No promotional use of children without guardian + steward consent |
| Unsupervised chat | No child–guest digital channels without moderation charter |
| Background checks | Future HOLD — legal framework required; no mock “verified safe” badges |
| Labor | No child labor framing in experiences; youth education only with care gate |

## Incident escalation (doctrine)

Future runtime must provide **human steward escalation** — not AI-only crisis response. Emergency services numbers are local operator responsibility; ZILWA doctrine does not replace national emergency systems.

# ZILWA — Listening Consent and Safeguarding (Phase 2B)

**Posture:** Human dignity first · **AMBER+ HOLD** · no repo storage of raw voices by default

## Principles

1. **Listening is a gift** — never extract stories for marketing.
2. **Consent is specific** — conversation ≠ permission to record, quote, or publish.
3. **Workers may fear retaliation** — offer anonymity; never name employers in public docs without approval.
4. **Elders and children** — family/steward approval required for any future use.
5. **ZILWA earns trust** — do not rush proposals while listening is incomplete.

## Before any conversation

- [ ] Explain purpose: improve tourism dignity — **not** a sales visit for ZILWA product
- [ ] Confirm participant is voluntary — can stop anytime
- [ ] Agree note-taking method: steward handwritten vs audio (audio only with written consent)
- [ ] Agree whether employer name, hotel name, or personal name may appear in **private** steward notes
- [ ] Confirm **nothing** goes to GitHub, apps, or AI tools without separate explicit approval

## Consent levels (document on paper)

| Level | Meaning |
| ----- | ------- |
| **Listen only** | Steward learns; no quotes retained |
| **Private notes** | Steward keeps offline notes; no names in repo |
| **Anonymized synthesis** | Themes may inform 3A; no identifiable quotes |
| **Named quote** | Written consent for specific quote and audience |
| **Recording** | Separate media consent form; family approval for elders/minors |

## Prohibited in 2B

- Filming workers without consent
- Uploading interviews to cloud drives tied to public repos
- Using listening sessions to pressure loyalty to Villas Caroline or ZILWA brand
- Promising jobs, payments, or pilot slots
- Collecting health data, child data, or guest records

## Villas Caroline context

Conversations may reference Villas Caroline as **one listening context** — not as commitment. See [ZILWA_VILLAS_CAROLINE_LISTENING_CONTEXT.md](ZILWA_VILLAS_CAROLINE_LISTENING_CONTEXT.md).

## If harm is disclosed

Follow local duty-of-care. Do not investigate as ZILWA. Refer to appropriate human support; document only what steward policy allows.

## After listening

Raw materials stay **offline** with AMK/steward custody. Repository receives only **governance docs and anonymized synthesis** when 3A is chartered — never raw interviews by default.

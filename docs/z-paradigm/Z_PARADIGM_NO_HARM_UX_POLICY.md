# Z-Paradigm — No-Harm UX Policy

**Phase:** Z-PARADIGM-1 (doctrine only)  
**Applies to:** All future Z-Paradigm surfaces (web, mobile, device UI, notifications)

---

## Purpose

Design **calm, honest, consent-based** experiences that respect attention, ecology, and human nervous systems. UX is part of **non-harm** — not growth hacking.

---

## Required patterns (when UI exists)

| Pattern | Rule |
| ------- | ---- |
| **Clear purpose** | Every screen states what it does and what it does **not** do (no medical/oracle claims). |
| **Stop / pause** | User can pause, go back, or exit without penalty. |
| **Consent before data** | No pre-ticked sensitive boxes; plain-language summaries. |
| **Export / delete** | When user data exists: export path and deletion request documented and reachable. |
| **Honest loading** | No fake progress or artificial delay to increase engagement. |
| **Error kindness** | Errors explain next safe step; no blame language toward user. |

---

## Forbidden patterns (dark UX)

| Forbidden | Why |
| --------- | --- |
| **Dark patterns** | Trick consent, hide unsubscribe, disguise ads as content. |
| **Infinite scroll** | Attention extraction without natural stopping point. |
| **Auto-play** | Video/audio starts without explicit user action (accessibility + calm). |
| **Anxiety notifications** | Urgency spam, streak loss fear, «you’ll miss out» pressure. |
| **Guilt-based donations** | Gratitude or support must stay optional (see compassion wellness gratitude law if linked). |
| **Pay-for-safety** | Wealth must not buy faster crisis response or trust tier. |
| **Countdown manipulation** | Fake scarcity timers for non-inventory digital goods. |
| **Social proof fabrication** | Fake «others are watching» or bot engagement. |
| **Biometric nudging** | Pressure to enable face/voice tracking for basic features. |

---

## Sensory and accessibility

- Respect **reduced motion** and **prefers-contrast** system settings in future CSS.  
- No strobe or rapid flash without warning.  
- Caption and transcript plan for any future media.  
- Touch targets and readable type per Z-UIL alignment ([Z_UNIVERSAL_INTERACTION_LANGUAGE.md](../design/Z_UNIVERSAL_INTERACTION_LANGUAGE.md)).

---

## Ecology-aligned UX

- Prefer **low-bandwidth** and **low-power** defaults (relevant to Z-Mimics concept).  
- Avoid «always refresh» dashboards that train compulsive checking.  
- Batch non-urgent updates; **no** anxiety cadence by default.

---

## AI-facing copy (future)

- Say **assistant**, **guide**, **orchestrator** — not conscious being.  
- Show **confidence as tentative** where models are used.  
- Never present model output as legal, medical, or spiritual authority.

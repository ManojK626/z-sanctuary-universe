## 14 DRP → engineering principles

| # | DRP compassion anchor (summary) | Z-Paradigm engineering principle |
| - | --------------------------------- | -------------------------------- |
| **1** | Non-harm first | **Harm budget:** reject features that increase anxiety, coercion, or ecological damage; document trade-offs. |
| **2** | Truthfulness | **Evidence labels:** distinguish doctrine, mock, prototype, and production; no fake runtime claims. |
| **3** | Consent | **Explicit opt-in:** data, notifications, sensors, and AI assistance; default off for sensitive lanes. |
| **4** | Privacy | **Data minimization:** collect least necessary; user-owned export/delete when data exists. |
| **5** | Dignity | **No dark patterns:** no shame loops, infinite scroll traps, or pay-for-safety tiers. |
| **6** | Inclusion | **Accessible defaults:** readable copy, pause/stop signals, multilingual readiness in design. |
| **7** | Elder & child protection | **Vulnerable-user gates:** stricter human review before features touching dependents. |
| **8** | Ecological respect | **Low-power bias:** Z-Mimics and infra favor efficiency; no wasteful always-on sensing. |
| **9** | Animal & lifeform care | **No exploitation framing:** maps and stories avoid commodifying life; cite compassion wellness doctrine where relevant. |
| **10** | Practitioner fairness | **Appealable trust:** humans review complaints; no AI-only punishment. |
| **11** | Community benefit | **Community-first metrics:** readiness scores judge **ecosystem** health, not user guilt. |
| **12** | Transparency | **Visible governance:** charters, receipts, and capability seeds stay public in hub docs. |
| **13** | Restraint in automation | **Smallest safe action:** suggest → verify → human decides; no silent deploy or repair. |
| **14** | Sacred authority with humans | **AMK gate:** merge, deploy, billing, providers, and live memory require explicit human approval. |

## Engineering checklist (before any future code)

1. Which DRP principles does this change support?  
2. Which principles could it violate?  
3. What is the **smallest** prototype that tests the idea?  
4. What receipt and rollback exist?  
5. Does copy use **assistant / guide** language only?  
6. Is **GREEN** being mistaken for launch permission? (Must be **no**.)

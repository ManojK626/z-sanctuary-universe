# GW-1 — Claim policy

**Phase:** Golden Website GW-1
**Date:** 2026-08-27
**Related:** [GW_1_PUBLICATION_CONTRACT.md](GW_1_PUBLICATION_CONTRACT.md)

What the Golden Website **may say** after a record is actually published. GW-1 publishes **nothing**, so these are constraints on future copy, candidate summaries, and Golden Guide AI answers.

## Hard equalities

| Must not confuse | Because |
| ---------------- | ------- |
| Public representation ≠ private authority | Federation is not a public command plane |
| Prototype ≠ production | HTML is a prototype class, not a shipped backend |
| Potential ≠ revenue | `POTENTIAL_NOT_VALIDATED` is not a sale |
| Visual ≠ implementation | A mockup or fixture is not the running system |
| AI answer ≠ evidence | Golden Guide AI may navigate the Twin; it does not create proof |
| Readiness ≠ deploy | Sealed slices are not production binds |

## Evidence state → allowed public language

| Overlay state | Must not be translated to | Allowed later (only after publication approval) |
| ------------- | ------------------------- | ----------------------------------------------- |
| `VERIFIED` | Unused in GW-0A/GW-1. If ever used, still needs the **publication** proof gate. | Exact verified **claim**, with citation |
| `SEALED` | “deployed”, “live in production”, “publicly launched” | “This slice is sealed in the sanctuary evidence record” |
| `QUALIFIED` | “proven”, “production-ready”, “commercially validated” | “Present in the hub / qualified internally; not a public proof” |
| `CONCEPT` | Any active-capability claim | Must stay visibly **concept** |
| `HOLD` | “coming soon” as a promise | “Held; not offered as a public capability” |
| `CLOSED` | “active”, “available”, “beta” | “Closed. Not an active public capability.” |

## Prototype class → allowed public language

| Prototype class | Must not imply |
| --------------- | -------------- |
| `WORKING` | Backend production capability, billing, public edge, live data |
| `PARTIAL` | Completeness |
| `SIMULATED` | Real operations |
| `CONCEPT` | A working exhibit |
| `PRIVATE` | Anything public |

62 HTML files on disk ≠ 62 public prototypes. 22 overlay rows ≠ 22 museum exhibits until each passes the Prototype Museum gate.

## Accessibility model

- Structured spatial map (CSS grid). No drag in this phase.
- Click/tap opens the detail panel.
- Keyboard: Tab into the map, arrow keys move between nodes, Enter/Space opens details, Escape closes, focus returns to the node.
- Visible focus; skip link; `main` is a skip target.
- Interactive targets at least 44px.
- Map usable at 1440, 768, and 390 widths; no horizontal overflow.
- `prefers-reduced-motion` disables animation.
- NVDA / VoiceOver remains a required human gate before public pilot.

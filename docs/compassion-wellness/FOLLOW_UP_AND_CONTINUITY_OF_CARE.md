# Follow-Up and Continuity of Care

**Phase:** 0 — Timeline doctrine (no scheduler runtime)

---

## Purpose

Ensure wellness, elder, and animal care paths do not end abruptly at session close — with **emotional safety**, practical aftercare, and governed follow-up reliability scoring.

---

## Care journey types

| Journey | Follow-up focus |
| -------------------------- | ---------------------------------------------------------------------------- |
| **Human wellness** | Muscle soreness norms, hydration, rest, stretch homework |
| **Elder care** | Loneliness check, medication **reminder user already uses** (no prescribing) |
| **Animal foster/adoption** | Adjustment, eating, bonding, environment safety |
| **Session aftercare** | Immediate debrief and stop-signal review |

---

## Emotional safety review

Post-session prompts (optional, user-controlled):

- Did you feel respected?
- Any pressure or discomfort to report?
- Would you like a human callback? (not AI-only)

Critical answers route to [TRUST_AND_FEEDBACK_ENGINE.md](TRUST_AND_FEEDBACK_ENGINE.md) human triage.

---

## Practical aftercare

| Reminder type | Example |
| ------------------ | ---------------------------------------------- |
| **Hydration** | Water after massage |
| **Rest** | Avoid heavy workout same day |
| **Stretch** | Gentle neck rolls if agreed in session |
| **Pet adjustment** | Quiet room, familiar blanket, litter placement |

---

## Suggested intervals

| Interval | Typical use |
| -------------------- | ----------------------------------------- |
| **Same day** | «How do you feel now?» — brief |
| **Day 1** | Soreness check, animal eating |
| **Week 1** | Habit continuation, foster settling |
| **Month 1** | Rehome stability, elder loneliness trend |
| **Custom recurring** | User-defined cadence with snooze and stop |

Future Phase 3 scheduler: **consent-based reminders only** — no spam.

---

## Follow-up reliability score

Part of trust profiles ([TRUST_AND_FEEDBACK_ENGINE.md](TRUST_AND_FEEDBACK_ENGINE.md)):

- Measures **did agreed check-ins happen** — not emotional quality scored by AI
- Missed check-ins → gentle prompt, not punishment
- Patterns of neglect → human review for practitioner/caregiver role

# Tools, Equipment, and Plant Support Policy

**Phase:** 0 — Policy only

**Scope:** Comfort and wellness support tools — not medical devices or miracle remedies.

---

## Approved tools (wellness context)

| Category | Examples |
| ------------------- | ------------------------------------------------ |
| **Massage tools** | Hand rollers, manual massage sticks |
| **Foam rollers** | Gentle myofascial release (non-clinical framing) |
| **Stretch bands** | Resistance bands for guided stretching |
| **Massage balls** | Lacrosse-style balls for pressure points |
| **Heat packs** | Microwavable herbal packs, warm towels |
| **Cushions** | Bolsters, knee wedges, neck supports |
| **Oils (external)** | Coconut oil, light carrier blends |

---

## Plant-based support (comfort only)

| Item | Use |
| ------------------------ | ------------------------------------------------ |
| **Aloe vera** | External soothing (patch test) |
| **Lavender** | Mild aroma — dilute; pet caution |
| **Chamomile** | Calming tea / compress context for humans |
| **Ginger warmth** | External warmth support concept |
| **Lemongrass** | Aroma only; strong dilution |
| **Oatmeal bath concept** | Animal skin comfort — vet if irritation persists |

---

## Safety notes

| Risk | Guidance |
| ----------------------------------------- | ------------------------------------------------------------------------------ |
| **Allergies** | Ingredient disclosure; stop on reaction |
| **Skin sensitivity** | Patch test; avoid broken skin |
| **Pregnancy** | Avoid deep abdominal pressure; consult licensed provider for medical questions |
| **Elderly fragility** | Lighter pressure; bone fragility awareness |
| **Pet toxicity** | Cats and dogs differ — many essential oils toxic to cats |
| **Concentrated essential oils near pets** | Forbidden without expert guidance |
| **Birds / small mammals** | Extra caution on airborne scents |

---

## Allowed / Forbidden claims

| Allowed | Forbidden |
| --------------------------- | ------------------------------------ |
| «May help you feel relaxed» | Cure, heal, or treat disease |
| «Comfort support only» | Detox or miracle plant claims |
| «Stop if irritation occurs» | Replacing medical or veterinary care |

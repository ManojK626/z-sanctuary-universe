# Revenue Models — Comparison (Analysis Only)

**Product:** Z-QUESTRA + Z-SME  
**No payment integrations in this doc**  
**Date:** 2026-06-11

## Models compared

| Model | Description | Fit (H/M/L) | Turtle safety | Household effort |
| ----- | ----------- | ----------- | ------------- | ---------------- |
| **One-time purchase** | Single download / kit price | **M** | **High** | Low ops after sale |
| **Subscription** | Monthly/annual facilitator access | **M–H** | **Medium** | Ongoing updates/support |
| **Freemium** | Free core + paid pro | **H** | **High** if free tier is truly local | Medium — two codepaths eventually |
| **Educational license** | School/NGO site license | **H** | **High** with adult/youth gates | Sales cycle longer |
| **Organization license** | Team seats + admin | **M** | **Medium** | Support burden rises |

---

## 1. One-time purchase

| Pros | Cons |
| ---- | ---- |
| Simple story; no churn | No recurring revenue |
| Lower subscription fatigue | Update expectations |
| Easier first Turtle experiment | Piracy / sharing risk (mitigate with honor system + updates) |

**Best for:** Workshop kit, curriculum bundle  
**Price band hypothesis:** €99–299 one-time  
**When registration review recommended:** First formal sales invoice

---

## 2. Subscription

| Pros | Cons |
| ---- | ---- |
| Predictable household income | Support expectation |
| Funds maintenance | Churn management |
| Aligns with SaaS norms | Stripe/subscription = Stage 4 gate |

**Best for:** Facilitators running monthly programs  
**Price band hypothesis:** €12–19/mo individual  
**Turtle note:** Start with **manual renewal** (invoice) before automated billing

---

## 3. Freemium

| Pros | Cons |
| ---- | ---- |
| Low friction discovery | Free users may never convert |
| Matches local-first ethos | Must define clear pro boundary |
| Good for first 10 users | Two-tier discipline required |

**Free tier hypothesis:** PlayGarden + comfort demo  
**Pro tier hypothesis:** Full workstation + Z-SME + export + facilitator PDFs  
**Risk:** Free tier must not require cloud — aligns with manifest

---

## 4. Educational license

| Pros | Cons |
| ---- | ---- |
| Aligns with product soul | Procurement slow |
| Higher ticket | Child-safety scrutiny if K–12 |
| NGO/grant budget paths | Documentation burden |

**Best for:** Personas B and D  
**Price band hypothesis:** €300–1,200 / year per site  
**Gate:** Adult-facilitator programs first; youth requires charter

---

## 5. Organization license

| Pros | Cons |
| ---- | ---- |
| Highest revenue per deal | Support + onboarding scale |
| B2B credibility | May need SLAs household cannot meet |

**Best for:** After 10 successful pilots — not first model  
**Defer until:** Household support playbook exists

---

## Recommended sequence (hypothesis)

```text
Phase 0 (now)     → Interviews + manual facilitated sessions (€0 or donation HOLD)
Phase 1           → One-time workshop kit OR educational pilot license (manual invoice)
Phase 2           → Subscription for facilitators who reorder
Phase 3           → Organization licenses with Anne/JB onboarding playbook
```

**Do not start at Phase 3.**

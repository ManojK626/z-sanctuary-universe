# Customer Personas — Hypotheses Only

**Product:** Z-QUESTRA + Z-SME
**Rule:** Every persona below is a **hypothesis** until validated by conversation.
**Date:** 2026-06-11

## How to read this doc

| Column             | Meaning                                               |
| ------------------ | ----------------------------------------------------- |
| **Fit**            | H–M–L vs current capabilities (not revenue certainty) |
| **Evidence**       | Hub capability or doctrine link                       |
| **Pay hypothesis** | Why they _might_ pay — requires validation            |

---

## Persona A — Accessibility-aware facilitator

| Field                   | Hypothesis                                                                                      |
| ----------------------- | ----------------------------------------------------------------------------------------------- |
| **Who**                 | Workshop facilitator, inclusion trainer, or teacher aide (adult audiences)                      |
| **Fit**                 | **High**                                                                                        |
| **Evidence**            | `comfort_modes`, `accessibility_toolset`, Z-Zebras readiness, EAA references in Phase 2.3B docs |
| **Problem**             | Needs demo tools that respect photophobia, motion sensitivity, and honest readiness language    |
| **Pay hypothesis**      | Monthly license or workshop kit for repeatable sessions                                         |
| **Validation question** | Would you pay for a **local-first** tool with no student data cloud?                            |

## Persona B — NGO / community program lead

| Field                   | Hypothesis                                                                            |
| ----------------------- | ------------------------------------------------------------------------------------- |
| **Who**                 | Community org running digital literacy or youth-adjacent programs (adult gatekeepers) |
| **Fit**                 | **Medium–High**                                                                       |
| **Evidence**            | PlayGarden safety policy; uncertainty kaleidoscope; non-predatory framing             |
| **Problem**             | Wants pattern/uncertainty literacy without gamified manipulation                      |
| **Pay hypothesis**      | Organization annual license                                                           |
| **Risk**                | Youth programs trigger child-safety charter — **adult-facilitator-only** until gated  |
| **Validation question** | Is local-only storage a **feature** or a **blocker** for your funders?                |

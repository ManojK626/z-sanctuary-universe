## Important — read first

> **The Quality Gate is a stewardship ritual.**  
> It exists to help humans think carefully before significant changes.  
> It informs decisions.  
> **It never replaces human judgment.**

This is **not** software.  
This is **not** an AI.  
This is **not** a dashboard.  
This is **not** an authorize / auto-pass button.

Boxes prepare. **Humans decide.**

---

## When to use it

Before any **significant** action, for example:

- New project, module, AI role, or dashboard claimed as canonical  
- Merge toward `main` · deploy · public launch · payment/legal copy  
- Major refactor · archive · deletion · cross-repo move  
- Anything that changes governance, backups, or registry truth  

Everyday tiny edits (typo, comment) need care — not necessarily this full ritual.

---

## The Steward's Takeoff Checklist

### Evidence

- [ ] Is the recommendation supported by evidence?  
- [ ] Are citations available (paths / reports / registries)?  
- [ ] Are NHV items clearly marked where confidence is low?

### Governance

- [ ] Constitution respected (Oath · Preservation · Evolution · Intelligence · Freshness · Stewardship)?  
- [ ] Stewardship principles respected (*strengthen stewardship?*)?  
- [ ] [Registry Atlas](Z_SANCTUARY_REGISTRY_ATLAS.md) consulted for the right source of truth?

### Preservation

- [ ] Backup verified (or NHV + explicit plan)?  
- [ ] Recovery path known?  
- [ ] Existing work protected (awaken, don't replace)?

### Cooperation

- [ ] Does this strengthen the ecosystem?  
- [ ] Does it avoid unnecessary duplication?  
- [ ] Does it awaken rather than replace?

### Responsibility

- [ ] Final human steward identified?  
- [ ] Risks understood?  
- [ ] Decision consciously accepted?

---

## Outcome (wording matters)

Do **not** stamp **PASS**.

Write only:

> **Ready for Steward Decision**

— or —

> **Not ready — pause until evidence / preservation / responsibility is clear**

The checklist does not authorize.  
It prepares.

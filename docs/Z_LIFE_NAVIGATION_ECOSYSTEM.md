# Z-Life Navigation Ecosystem — Wider Human Support Layer

**Layer:** 3 of 3 (Reality Navigation System)
**Phase:** Z-RNS-LIFE-NAV-1 (sketch — docs only in Z-RNS-ARCH-1)
**Parent:** [Z_REALITY_NAVIGATION_SYSTEM.md](Z_REALITY_NAVIGATION_SYSTEM.md)

---

## Purpose

Extend reality navigation beyond legal evidence into **whole-life support**: health timelines, accessibility, multilingual awareness, and calm navigation under stress — without claiming medical, therapeutic, or legal authority.

---

## Scope (planned modules)

| Module              | Intent                                | Boundary                                        |
| ------------------- | ------------------------------------- | ----------------------------------------------- |
| Health Timeline     | Track medical events privately        | Not a medical record system; not diagnosis      |
| Accessibility modes | Blind, voice, dyslexia, simplified UI | UX charter — not assistive device certification |
| Multilingual packs  | UI + glossary support                 | Human review for sensitive terms                |
| Support node map    | NGOs, charities, helplines (metadata) | Directory only — no auto-referral               |
| Calm navigation     | Breathing, pacing, break reminders    | Wellness support — not therapy claim            |

---

## Relation to Z-SMA (True Human Experience)

Where personal life stories intersect legal navigation, dignity-first rules from [Z_SMA_TRUE_HUMAN_EXPERIENCE_SANCTUARY.md](Z_SMA_TRUE_HUMAN_EXPERIENCE_SANCTUARY.md) apply:

- Default `private_only`
- Human consent before any sharing
- No trauma text in public seeds
- No AI voice of real people without charter

---

## World Service Mode (Phase 8 target)

Accessibility is a **first-class design requirement**, not a late add-on:

- Screen reader and keyboard paths
- Voice navigation (local-only charter)
- Low-literacy simplified copy
- High-contrast and dyslexia-friendly typography options

---

## Locked law

```text
Support directory ≠ endorsement.
Calm prompts ≠ medical care.
Accessibility UX ≠ certified medical device.

```

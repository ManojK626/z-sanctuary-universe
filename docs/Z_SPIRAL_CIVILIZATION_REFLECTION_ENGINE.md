# Z-SPIRAL — Civilization Reflection Engine (Phase 0)

**Formal lane:** Z-SPIRAL-0  
**Alias:** Civilization Reflection Engine, external awareness + evolution intelligence  
**Hub:** Z-Sanctuary Universe

## Definition

```text
Z-SPIRAL
=
External Awareness + Internal Governance + Evolution Intelligence
```

Z-SPIRAL is **not** a search bot, hype AI, or crawler swarm. It is the **outer ring** of the civilization stack:

```text
“What is the outside world evolving toward,
 and what should we responsibly learn from it?”
```

**Standing law:**

```text
observe → filter → compare → classify → adapt (suggest) → human decides
Z-SPIRAL NEVER directly upgrades the ecosystem
14 DRP overrides all formulas — formula never reaches zero; system is self-correcting, not self-ruling
```

Machine policy: `data/z_spiral_reflection_policy.json`.

---

## Mission

Z-SPIRAL produces **reflection artifacts only**:

| Output type | Purpose |
| --- | --- |
| **Reflection receipts** | Timestamped, sourced summaries of external signals |
| **Insight maps** | Classified trends vs hub topology (via Z-ECO-MAP) |
| **Fusion suggestions** | Routed to Z-FUSION — never auto-merge |
| **Risk warnings** | Anti-patterns, trust collapses, unethical automation |
| **Opportunity signals** | Low-risk learning lanes — still gated by Z-ATE |

Then the **civilization loop**:

```text
Z-MDE   → overlap check
Z-FUSION → compatibility / co-design
Z-ATE   → trust / autonomy score
AMK     → final authority
```

---

## Non-mission

Z-SPIRAL is **not**:

- copying trends, stealing ideas, or hype following
- auto-ingesting internet chaos or unbounded crawlers
- upgrading modules, deploying, or mutating registries
- replacing Z-ATE, 14 DRP, or AMK sacred gates
- “infinite AGI” or autonomous external mesh execution
- public marketing of protected formula internals

## External awareness categories (Phase 0 taxonomy)

### 1. AI ecosystem trends

Governance models, orchestration, memory systems, agent routing, multimodal patterns — **compare** to hub posture; do not adopt blindly.

### 2. Security intelligence

Attack patterns, AI misuse, social engineering, infra resilience ideas — feed **risk warnings** and Z-ATE L4/L5 triggers.

### 3. Human civilization patterns

Education, accessibility, collaboration, workflow models, humane UX — align with 14 DRP compassion routing.

### 4. Technology evolution

Deployment shifts, edge systems, distributed compute, cloud resilience, local-first infrastructure — cross-check [Z_DEPLOYMENT_READINESS_OVERSEER.md](./Z_DEPLOYMENT_READINESS_OVERSEER.md); production bind stays **HOLD** without charter.

### 5. Ethical failures (anti-pattern memory)

Failed AI launches, trust collapses, exploitative systems, unethical automation — **highest protection value**; default posture `SUPERVISED_REQUIRED` or `AMK_REQUIRED`.

---

## Processing pipeline (mandatory order)

```text
1. Source charter check (human-approved inputs only in Phase 0)
2. 14 DRP filter (non-harm, no deception, no hidden authority)
3. Classify into awareness category
4. Compare to Z-ECO-MAP topology (placement, isolation, payment lanes)
5. Z-MDE overlap scan (do we already have this pattern?)
6. Z-FUSION compatibility hint (if overlap suggests combine)
7. Z-ATE trust label for any proposed internal action
8. Emit reflection receipt — no apply
9. AMK reviews L3+; L4/L5 sacred moves never auto-flow
```

## Knowledge tree posture (Z1000 / mango tree metaphor)

Modules and patterns may **grow** by:

- verified contribution
- governance score
- usefulness and stability
- safety and collaboration quality

**Not** by ego, hype, or raw module count.

| Signal | Civilization response |
| --- | --- |
| Weak / duplicate | Stagnate or merge (Z-MDE + Z-FUSION) |
| Valuable / stable | Evolve with receipts |
| Unstable / unethical | Isolate + BLOCKED via Z-ATE |

Phase 0 documents the metaphor only — **no** automated scoring runtime.

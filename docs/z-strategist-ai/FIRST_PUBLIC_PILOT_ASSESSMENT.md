# First Public Pilot Assessment — Z-Strategist AI

**Posture:** Strategic hypothesis · **not** launch approval  
**Owner review:** AMK-Goku  
**Date:** 2026-06-11 · Wave 2

## Question

Which Wave 1 project is **most likely** to reach Stage 3 (pre-deployment / public beta **planning**) **first** — without assuming ZILWA, Z-Tourism, or any commercial lane by default?

## Method

Scored on five lenses (higher = easier path to **low-risk static** public awareness, not revenue):

1. **Privacy / legal surface** — lower customer data = better  
2. **Revenue activation risk** — no payments path = better for first pilot  
3. **Documentation completeness** — doctrine pack on disk  
4. **Technical path** — static HTML / mock vs full product  
5. **Human / steward gates** — listening and consent burden  

**Explicitly excluded from “first pilot”:** hub Core as a product, Compassion Wellness (legal sensitivity), any Stage 4+ commercial lane.

## Recommended first pilot (hypothesis)

Primary candidate: Z-EarthConscience (Z-PEE Planetary Ethics)

Why not ZILWA or Z-Tourism first:

- ZILWA is the **deepest** cultural lane — it deserves **listening completion** (2B, Mauritius field work) before public beta framing.
- Z-Tourism **inherits** ZILWA doctrine but lacks a **standalone** tourism pack and registration is correctly **Not yet**.
- Z-EarthConscience can ship **awareness-only** static education aligned with existing reef/ocean/legacy **patterns** without opening bookings or subscriptions.

**Secondary candidate: Z-Nexus static mock dashboard** — when AMK approves HTML from [Z_NEXUS_ENGINE_MOCK_DASHBOARD_SPEC.md](../z-nexus-engine/Z_NEXUS_ENGINE_MOCK_DASHBOARD_SPEC.md).

# Z-Strategist AI — Readiness Stages

**Posture:** Governance taxonomy only · not operational state in code

## Overview

| Stage | Name | Summary |
| ----- | --------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| **0** | Idea | Vision only. No public users. No revenue. |
| **1** | Doctrine | Documents, principles, blueprints, governance. |
| **2** | Prototype | Internal build/testing. No public customers. |
| **3** | Pre-Deployment | Public beta or external testers **may be planned**. Compliance review triggered. |
| **4** | Commercial Activation | Payments, contracts, subscriptions, bookings, commissions, ads, or customer services **planned**. Registration review recommended. |
| **5** | Revenue Operations | Revenue active or expected imminently. Tax/VAT/accounting review recommended. |

## Stage 0 — Idea

- Vision, naming, or sketch exists
- No public URL, no users, no income
- **Typical indicators:** Vision UNKNOWN/AMBER; all commercial indicators HOLD or UNKNOWN

## Stage 1 — Doctrine

- Written scope, ethics, receipts, registries
- Static HTML/mock exhibits allowed (Turtle Mode)
- **No** public customer relationship

## Stage 2 — Prototype

- Internal demos, local builds, sandbox testing
- May include multi-root workspace development
- **Still no** public launch or revenue

## Stage 3 — Pre-Deployment

Triggers when **any** of:

- public beta planned
- external testers invited
- production-like hosting considered
- real user data handling considered (even minimally)

**Actions:** security review recommended, privacy review recommended, deployment risk assessment, human gate required before go-live.

## Stage 4 — Commercial Activation

Triggers when **any** of:

- payments, subscriptions, bookings, commissions
- ads or sponsorship revenue
- client contracts or SLAs
- formal partnerships with revenue share
- hiring workers for the product

**Actions:** registration review recommended, banking review recommended, terms/policies review recommended, **human/legal/accounting gate required**.

## Stage 5 — Revenue Operations

- Revenue is live or launch is imminent with charging
- **Actions:** tax/VAT review recommended, accounting review recommended, ongoing compliance monitoring (human-led)

## Stage transitions

| From → To | Gate |
| ------------ | ----------------------------------------- |
| 0 → 1 | Document charter + owner |
| 1 → 2 | Build rules + privacy note |
| 2 → 3 | Security + privacy review recommended |
| 3 → 4 | Registration + banking review recommended |
| 4 → 5 | Tax/VAT + accounting review recommended |
| Any → Deploy | **AMK-Goku Final Gate** |

## Not allowed to launch

Projects remain **HOLD** at any stage if:

- human gate = Hold
- deployment risk = RED
- revenue activation risk = RED without review
- missing owner, purpose, user group, or privacy note

**Wave 3 · Posture:** Learning gate · **not** deployment or business readiness

## Core distinction

| Question type | Asks | Wave |
| ------------- | ---- | ---- |
| **Business readiness** | Company, VAT, banking, contracts? | Stage 4–5 (not yet) |
| **Deployment readiness** | Can we ship runtime, APIs, payments? | Technical / overseer lanes |
| **Pilot readiness** | Can we **learn** safely in public view? | **Wave 3** |

```text
Vision ≠ Product
Doctrine ≠ Deployment
Readiness ≠ Revenue
Pilot ≠ Launch
```

A pilot may be **publicly viewable** static content with **no** customers, **no** revenue, and **no** registration review recommended.

## The five pilot questions

Every pilot candidate must answer these before AMK clears Human Gate for public view:

### 1. Which project could safely be viewed by the public?

- Owner named; purpose is education / awareness / ethics — not clinical, booking, or payment
- Privacy note documents what is **not** collected
- No undeclared data capture, accounts, or subscriptions

### 2. What would the public actually see?

- Describe **exact surfaces**: static HTML pages, read-only mock nodes, PDF-style cards
- List what is **mock** vs **verified** (default: illustrative only)
- No hidden runtime, trackers, or payment buttons

### 3. What feedback are we seeking?

- Learning goals: comprehension, tone, cultural respect, clarity, accessibility
- **Not** conversion, sales, or booking intent in Wave 3 pilots
- Optional: steward / community comment channel — human-moderated, no auto-publish

### 4. What risks exist?

| Risk class | Examples |
| ---------- | -------- |
| **Claim risk** | False environmental, health, or impact claims |
| **Cultural risk** | Tourism or sacred knowledge without consent |
| **Legal surface** | Coaching, therapy, or advice language |
| **Dependency risk** | Upstream HOLD blocks (e.g. ZILWA listening incomplete) |
| **Technical risk** | Live APIs, auth, or payments sneaking in |

### 5. What does success look like?

Success = **learning receipts**, not revenue:

- Documented visitor/steward feedback themes
- No boundary incidents (privacy, claims, consent)
- Pilot scope unchanged — still no Stage 4 triggers
- AMK decision: extend, pause, or pivot — documented

From Mauritius, a Wave 3 pilot can test:

- Governance and documentation discipline
- Public engagement tone
- Awareness campaign **learning**

Without requiring:

- VAT registration
- Subscriptions or bookings

| VAT | **No** |

## Pilot readiness indicators (Wave 3 only)

These sit **beside** AMK-Goku indicators — they do not replace them.

| Pilot signal | Meaning |
| ------------ | ------- |
| **LEARN-READY** | Five questions answered; risks documented; static scope only |
| **LEARN-HOLD** | Missing consent, charter, or upstream dependency |
| **LEARN-NO** | Health, payment, or booking surface — wrong lane for Wave 3 |

No project is **LEARN-READY** for AMK Final Gate until sheets are reviewed and Human Gate moves from Hold.

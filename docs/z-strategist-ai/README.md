# Z-Strategist AI — Readiness Layer Index

**Core name:** Z-STRATEGIST-AI
**Display name:** Z-Strategist AI — AMK-Goku Deployment Readiness Engine
**Posture:** Docs-only · **AMBER+ HOLD** · not legal or tax advice

## Purpose

Structured readiness doctrine and **AMK-Goku indicators** for every root project in the Z-Sanctuary ecosystem — so we can see at a glance:

- which projects are still ideas,
- which are prototypes,
- which are near deployment,
- which need **registration review recommended**,
- which need **tax/VAT review recommended** or **banking review recommended**,
- which are **not allowed to launch yet**.

This is a **governance signal system**, not a legal-advice engine.

## Workflow

1. Copy [PROJECT_READINESS_TEMPLATE.md](PROJECT_READINESS_TEMPLATE.md) per project
2. Assign stage (0–5) and indicators (GREEN / AMBER / RED / HOLD / UNKNOWN)
3. Flag review triggers — never auto-require registration
4. **AMK-Goku Final Gate** before any deploy or revenue activation

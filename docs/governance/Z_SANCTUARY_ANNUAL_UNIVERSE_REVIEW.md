**System ID:** Z-ANNUAL-UNIVERSE-REVIEW-1  
**Version:** 1.0

**Owner:** AMK-Goku (human steward)  
**Status:** Canonical practice · documentation only  
**Cadence:** **Once per year** (calendar or stewardship anniversary — steward chooses)

---

## Purpose

The foundation is **living** — not frozen, not unstable.

Once a year, the human steward reviews governance doctrine so wisdom can evolve **deliberately**, not by accident or drift.

> **Knowledge grows. Wisdom guides. Governance protects. Humanity decides.**

This practice complements [Foundation Consolidation](Z_SANCTUARY_FOUNDATION_CONSOLIDATION.md) (deeper, post-holiday when authorized) and [UNIVERSE_CHANGELOG.md](../UNIVERSE_CHANGELOG.md) (milestone memory).

---

## The five questions

Ask these every annual review:

| # | Question |
| - | -------- |
| 1 | **Are these doctrines still useful?** |
| 2 | **Which ones have proven themselves?** |
| 3 | **Which ones are rarely used?** |
| 4 | **Which should evolve?** |
| 5 | **Which should remain unchanged?** |

Record outcomes in the civilization changelog — **why** a doctrine was kept, evolved, or retired, not just that files changed.

## Outcomes (allowed)

| Outcome | Action |
| ------- | ------ |
| **Remain unchanged** | Note in changelog: "doctrine affirmed YYYY" |
| **Evolve** | Small doc update + human PR · Turtle branch |
| **Promote** | Consolidation path — timeless principle → foundation |
| **Retire** | Human gate · archive link in changelog · never silent delete |
| **Defer** | Explicit "review again next year" — rare-use is not failure |

---

## Hard boundaries

- **No** automatic doctrine mutation from AI or scripts  
- **No** bypass of Merge Hold, DRP, or sacred gates during review  
- **No** annual review used to rush runtime or skip Track A  
- Evolution stays **modular** — principles travel, products do not merge

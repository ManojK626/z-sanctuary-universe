# Compassion Barter — Earth Impact Dashboard (Concept)

**Phase:** Z-COMPASSION-BARTER-0 — sustainability doctrine only

---

## Purpose

Describe a **Mother Earth** impact surface that celebrates circular swaps — without claiming verified environmental certification or deploying live analytics in Phase 0.

**Locked phrase:** Earth dashboard concept ≠ verified environmental certification.

---

## Impact dimensions (conceptual metrics)

| Metric | Meaning | Data source (future) | Phase 0 |
| -------------------------------- | ----------------------------------- | ----------------------------- | -------- |
| **Waste diverted** | Items reused instead of landfill | Self-report + moderation | Doctrine |
| **Carbon saved (estimate)** | Rough model vs new purchase | Published formula doc only | Doctrine |
| **Repair/reuse/recycle routing** | Items sent to repair vs recycle | User-selected disposition | Doctrine |
| **Community seeds** | «One Trade, One Seed» symbolic acts | Honor system + steward verify | Doctrine |
| **Local circular velocity** | Swaps per community per month | Aggregated counts (future) | Not live |

All figures are **illustrative or self-reported** until third-party verification charter exists.

---

## «One Trade, One Seed» (concept only)

When a swap completes (future UI):

- Optional prompt to plant a seed, donate to community garden, or support local reforestation partner
- Symbolic karma acknowledgment — not carbon offset trading
- No mandatory fee or guilt copy

---

## Mother Earth dashboard (concept)

Read-only community view (future prototype):

- Totals: items swapped, estimated kg diverted, repair referrals
- Stories: anonymized swap success (human-approved)
- Repair shop and recycler directory links (static docs first)
- **No** real-time map tracking of users or items

Banner copy (future UI):

```text
Estimates for inspiration — not certified environmental claims.
One Trade, One Seed — community kindness, not carbon credits.
```

---

## Repair / reuse / recycle routing

| Route | When | Phase 0 |
| ---------------- | ------------------------ | --------------------------------------------- |
| **Reuse (swap)** | Item still usable | Default journey |
| **Repair** | Fixable with local maker | Link to repair doctrine / future directory |
| **Recycle** | End of useful life | Point to local recycler info — no auto pickup |
| **Refuse** | Unsafe or prohibited | Safety doc blocks listing |

---

## Forbidden claims

- «Certified carbon neutral» without licensed verifier
- Official UN/ISO badge without contract
- Shaming users who skip seed pledge
- Selling impact data to advertisers

---

## Human gates before live dashboard

1. AMK approval
2. Legal review on environmental marketing claims
3. Privacy review on aggregated community data
4. Methodology doc for any published CO₂ estimate

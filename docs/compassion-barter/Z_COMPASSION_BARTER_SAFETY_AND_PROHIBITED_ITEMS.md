# Compassion Barter — Safety and Prohibited Items

**Phase:** Z-COMPASSION-BARTER-0 — policy doctrine only

---

## Safety principles

1. **Honesty** — item condition and ownership must be truthfully described
2. **Non-harm** — no weapons, hazardous, illegal, or exploitative listings
3. **Dignity** — no shaming, coercion, or predatory targeting of vulnerable users
4. **Human moderation** — AI may organize reports in future; humans decide outcomes
5. **Child safety** — extra gates for minors and child-adjacent items (future charter)

---

## Prohibited items (non-exhaustive)

| Category | Examples | Action |
| --------------------------- | ---------------------------------------------------------- | ---------------------------------------- |
| **Weapons** | Firearms, ammunition, blades marketed as weapons | Block listing concept |
| **Hazardous materials** | Explosives, toxic chemicals, radioactive items | Block |
| **Illegal goods** | Stolen property, counterfeit goods, pirated media for sale | Block + report pathway |
| **Controlled substances** | Drugs requiring prescription; illegal substances | Block |
| **Unsafe medical products** | Unapproved devices, miracle cure kits | Block |
| **Human exploitation** | Trafficking-adjacent, coercion, adult services barter | Block + escalate |
| **Live animals (sale)** | Commercial animal trading; fighting animals | Block — compassion animal lanes separate |
| **Personal data** | Databases, identity documents for sale | Block |
| **Surveillance tools** | Covert cameras, stalkerware | Block |

---

## Restricted (human review before any future listing)

| Category | Gate |
| ---------------------------- | ---------------------------- |
| High-value electronics | Escrow concept + ID charter |
| Baby and child items | Safety recall check (human) |
| Food surplus | Allergy labeling + local law |
| Medicines (OTC) | Jurisdiction + safety copy |
| Tools and workshop equipment | Safety instructions required |

---

## Item condition honesty

Offerers must declare:

- Functional vs parts-only
- Hygiene-sensitive items cleaned/disclosed
- Known defects visible in description
- «As-is» without miracle performance claims

Misrepresentation triggers dispute path — not instant AI ban.

---

## Reporting and moderation (concept)

```text
User report
    → Category (safety / fraud / prohibited / harassment)
    → Human triage queue
    → Outcome: remove listing / warn / suspend pending review / escalate authorities (human decision)
```

**Forbidden:** public «wall of shame»; automated permanent bans without appeal.

---

## Vulnerable-user gates

| Group | Extra protection (concept) |
| -------------------- | ------------------------------------------------------- |
| **Elders** | Guardian optional; no high-pressure swap copy |
| **Disabled users** | Accessible forms; meet-in-public defaults |
| **Children** | No direct marketplace accounts without guardian charter |
| **Low-income users** | No pay-for-safety; no wealth-based match priority |

---

## Meeting safety (future in-person exchange)

- Prefer public meet locations
- Bring a friend option documented
- No home address required in Phase 0 doctrine
- Stop signal honored immediately

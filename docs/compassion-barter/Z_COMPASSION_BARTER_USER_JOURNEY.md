# Compassion Barter — User Journey (Doctrine)

**Phase:** Z-COMPASSION-BARTER-0 — design only

---

## Journey overview

```text
Discover (local/community scope)
    → List or offer (honest description)
    → Match or propose swap (human-initiated)
    → Agree terms (plain language)
    → Exchange (in-person or future shipping — charter only)
    → Confirm + optional feedback
    → Impact reflection (Earth dashboard concept)
```

All steps are **doctrine** in Phase 0. No live UI, API, or automation.

---

## Actor types

| Actor | Role |
| ---------------------------- | -------------------------------------------------------- |
| **Offerer** | Posts item/skill with honest condition |
| **Seeker** | Browses or requests swap |
| **Community steward** | Human moderator (future); not AI-only |
| **Vulnerable-user guardian** | Optional proxy for elder/disabled users (future charter) |

---

## Stage detail

### 1. Discover

- Community-scoped visibility (not global surveillance map)
- Categories: goods, skills, repair, surplus food (policy-gated), tools
- **No** dark patterns, infinite scroll traps, or urgency manipulation

### 2. List or offer

Required honesty fields (conceptual):

- Title and description
- Condition (new / good / fair / parts-only)
- Photos optional in future — **no** hidden metadata harvest in Phase 0
- Prohibited items blocked per [Z_COMPASSION_BARTER_SAFETY_AND_PROHIBITED_ITEMS.md](Z_COMPASSION_BARTER_SAFETY_AND_PROHIBITED_ITEMS.md)

### 3. Match or propose

- Direct swap proposal or pure gift offer
- Optional internal credits per [Z_COMPASSION_BARTER_CREDIT_KARMA_MODEL.md](Z_COMPASSION_BARTER_CREDIT_KARMA_MODEL.md)
- **AI matching** — future-gated only; human approves any suggestion

### 4. Agree terms

- What each party gives and receives
- Meeting location safety notes (future form)
- Escrow concept only if high-trust lane chartered — see escrow doc

### 5. Exchange

- In-person handoff preferred in early phases
- Shipping — **concept only**; no courier API in Phase 0
- Stop / cancel anytime before handoff without penalty shaming

### 6. Confirm and feedback

- Multi-dimensional trust (condition accuracy, communication, punctuality)
- **Not** a single karma score for punishment
- Disputes → [Z_COMPASSION_BARTER_ESCROW_AND_DISPUTES.md](Z_COMPASSION_BARTER_ESCROW_AND_DISPUTES.md)

### 7. Impact reflection

- Optional link to Earth impact dashboard **concept**
- «One Trade, One Seed» — symbolic community contribution; not verified carbon credit

---

## Vulnerable-user gates

- Elder and disabled users may use simplified flows (future)
- Guardian consent for high-value or recurring swaps (future charter)
- No coercive «must swap» nudges

---

## Forbidden journey patterns

- Anonymous high-risk exchanges without safety charter
- Pay-to-rank visibility
- Auto-accept swaps without human confirmation
- Public shaming for declined trades

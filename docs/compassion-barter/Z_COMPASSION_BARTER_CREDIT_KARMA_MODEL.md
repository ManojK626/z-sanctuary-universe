# Compassion Barter — Credit / Karma / Gift Model

**Phase:** Z-COMPASSION-BARTER-0 — economy doctrine only

---

## Purpose

Describe optional **non-financial** exchange layers that support circular sharing without becoming a token launch, payment product, or legal currency.

---

## Exchange modes

| Mode | Description | Phase 0 |
| -------------------------------- | --------------------------------- | -------------------------------------- |
| **Direct barter** | Item A ↔ Item B | Doctrine |
| **Pure gift** | Give without expectation | Doctrine |
| **Optional internal credits** | Community-scoped ledger concept | Doctrine only — no runtime ledger |
| **Eco-credit / Sanctuary karma** | Reputation + contribution signals | Doctrine only — not spendable currency |
| **Hybrid** | Gift + karma acknowledgment | Future forms only |

---

## Internal credits (concept)

**May become (with charter):**

- Local community credit for skill hours or surplus goods
- Expiring gently to prevent hoarding (human-set policy)
- Transparent rules published before any ledger exists

**Must not become without legal + AMK gate:**

- Withdrawable cash equivalent
- Interest-bearing account
- Securities or investment framing
- Cross-border money transmission

**Locked phrase:** Credit model ≠ financial product.

---

## Sanctuary karma / eco-credit (concept)

| Dimension | Measures (concept) | Must not |
| ------------------------- | --------------------------------------------------------- | ----------------------------------- |
| **Reliability** | Shows up, honest descriptions | Permanent guilt score |
| **Generosity** | Gifts, repair help, mentoring | Pay-for-trust tiers |
| **Circular contribution** | Reuse/repair routing | Public shaming leaderboard |
| **Earth kindness** | Seeds planted, waste diverted (self-reported + moderated) | Verified carbon certification claim |

**Locked phrase:** Karma score ≠ legal currency.

Karma is **community recognition**, not legal tender, not collateral, not enforceable debt.

---

## Pure gift mode

- Default-friendly path for surplus and compassion flows
- No mandatory tip or karma «tax»
- Gratitude optional — aligns with compassion wellness gratitude law when linked

---

## Blockchain and tokens

| Forbidden in Phase 0+ doctrine until explicit charter | Reason |
| ----------------------------------------------------- | --------------------------------- |
| Token launch | Financial and regulatory risk |
| NFT item certificates as money substitutes | Speculation drift |
| DeFi collateral | Outside compassion barter purpose |
| On-chain karma | Irreversible reputation harm |

---

## Allowed / forbidden summary

| Allowed (doctrine) | Forbidden |
| --------------------------------- | ----------------------------- |
| Describe credit rules in markdown | Deploy wallet or payment rail |
| Gift-first copy and flows | Mandatory internal currency |
| Human-reviewed karma notes | AI-only credit penalties |
| Transparent policy docs | Hidden exchange rates to cash |

---

## Human gates

Any move from **doctrine** to **ledger implementation** requires:

1. AMK approval
2. Legal review (financial product boundaries)
3. Privacy review (user data in ledger)
4. Safety review (fraud and vulnerable-user lanes)
